# Deprecated Configs

These configs are intentionally retained instead of deleted.

They are not active mainline entrypoints. Use `configs/main.yaml` for the clean unified FLM/RoPE route.

## Folders

- `anti_collapse_failed/`: anti-collapse experiments that preserved understanding but did not fix text-to-image collapse.
- `superseded_generation_mixes/`: older generation mix variants superseded by the `gen124` mainline.

Deprecated configs should only be used to reproduce old records.
