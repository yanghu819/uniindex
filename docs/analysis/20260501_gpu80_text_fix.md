## Takeaways

- The PAD/BOS bug was real and the fix helped, but it did not solve image-to-text understanding.
- Joint task loss can get very low while image-to-text remains weak; joint loss is not a reliable proxy for image-conditioned text accuracy.
- The image-to-text task loss decreases from roughly 2.97 to 1.92, but that is still not enough for strong digit-word generation.
- The next bottleneck is likely objective/sampling mismatch and weak conditioning, not raw GPU throughput.

## Reuse

- Keep checkpoint namespacing for every experiment.
- Use no-HF evaluation scripts that load existing tokenizer state directly.
- Compare constrained label accuracy and parsed generated text accuracy separately.
- Treat generated text distribution collapse as a first-class diagnostic, not only exact match.
